NetBox

NetBox is the source of truth: it holds the intended state that every environment is built from.

Explanation

Each approved form entry becomes NetBox objects: tenants, VRFs, prefixes, VLANs, VNIs, devices, interfaces and custom fields for the ACI policy model. NetBox then describes what the network should look like, independent of any vendor controller.

Because NetBox is the single source of truth, drift can be measured by comparing NetBox with the live controller. The NetBox ACI Tenants page on this site already does this for the ACI sandbox, and the YAML Model page shows the Network-as-Code model generated from NetBox.
