Domains, types and how to query this

Domains group faults by area: Access (ports, AAEPs, domains), External (L3Out / L2Out), Framework (APIC platform), Infra (fabric infrastructure), Management, Security, Tenant, and SYSTEM WIDE (the dashboard total).

Types are Communications, Config, Environmental and Operational. The widgets show critical, major, minor and warning (info and cleared are omitted, as in the APIC dashboard).
