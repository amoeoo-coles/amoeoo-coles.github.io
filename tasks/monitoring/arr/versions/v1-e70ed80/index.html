ARR Fault Counts Waiting for data

This is the Fault Counts page for ARR – ACI Rack Rental. It uses the same layout as AOAPIC Fault Counts (dashboard-style By Domain and By Type tables, Hide Acked / Hide Delegated, and a clickable list of

faultInstfaultDelegate
records). It will be filled from a live read-only APIC query or a fault export once those exist. No numbers are shown as counts, because none have been collected.

No “data as of” time yet — there is no ARR APIC snapshot on the box.

Waiting for ARR APIC access. Nothing on this page is estimated or copied from AOAPIC or from the demo screenshot. To fill it, send the ARR APIC HTTPS URL plus either read-only credentials or a read-only export of faultCountsWithDetails, faultInst and faultDelegate.

What will appear here

  • Fault Counts By Domain: SYSTEM WIDE, Access, External, Framework, Infra, Management, Security, Tenant.
  • Fault Counts By Type: Communications, Config, Environmental, Operational.
  • Columns for critical, major, minor and warning, with the same severity icons as the APIC dashboard.
  • Working Hide Acked Faults and Hide Delegated Faults toggles, applied client-side.
  • Clickable counts that open a list of those faults (code, severity, DN chip, description, created time in AEDT, ack status).
  • A “data as of HH:MM AEDT” stamp from the collection run.
