Diagrams of the Cisco Live LTRDCN-2143 pod1 Network-as-Code model published as aci-lab-guide-pod1-20261110-2356.nac.yaml. Every box is an object from that file, or a name the file references but does not define (for example k8s_vrf). Boxes link to the matching ACI Policy page; a Lab badge opens the lab-guide step when one applies. Nothing here is pushed to a fabric. Style matches the NetBox ACI tenant diagrams.
