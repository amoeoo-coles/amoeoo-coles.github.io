Tenant aci_p01_tenant

Diagrams · Tenant aci_p01_tenant · Tenant msite_p01_tenant · Access policy chain · L3Out and external connectivity · Contracts and filters · All objects

Diagrams of the Cisco Live LTRDCN-2143 pod1 Network-as-Code model published as aci-lab-guide-pod1-20261110-2356.nac.yaml. Every box is an object from that file, or a name the file references but does not define (for example k8s_vrf). Boxes link to the matching ACI Policy page; a Lab badge opens the lab-guide step when one applies. Nothing here is pushed to a fabric. Style matches the NetBox ACI tenant diagrams.

Tenant → VRF → bridge domain (subnet in the BD box) → application profile → EPG, ESG, uSeg and external EPG. Blue arrows are contracts (provider to consumer). The VRF k8s_vrf and L3Out k8s are referenced by the mgmt BD and DHCP policy but are not defined in this YAML.

Defined in the lab-guide YAMLReferenced, not defined in this YAML
Referenced, not defined in this YAML. These names appear as references in the model (or in a lab step) but have no defining stanza here, so they are drawn as warning boxes and are not invented: vrf k8s_vrf, l3out k8s, ext_epg k8s-epg, contract web-ltraci-2143, contract mgmt-ltraci-2143.

The Multi-Site orchestrator lab step also mentions the DC1 VMM domain clemea-rsite-dc1; that object is not in this YAML and is not drawn.
