Contracts and filters

Diagrams · Tenant aci_p01_tenant · Tenant msite_p01_tenant · Access policy chain · L3Out and external connectivity · Contracts and filters · All objects

Diagrams of the Cisco Live LTRDCN-2143 pod1 Network-as-Code model published as aci-demo-guide-pod1-20261110-2356.nac.yaml. Every box is an object from that file, or a name the file references but does not define (for example k8s_vrf). Boxes link to the matching ACI Policy page; a Demo badge opens the demo-guide step when one applies. Nothing here is pushed to a fabric. Style matches the NetBox ACI tenant diagrams.

aci_p01_con (filter aci_p01_fil: icmp and ssh/tcp/22) is provided by the app EPG and consumed by the web EPG. The web EPG also provides common/web-ltraci-2143, consumed by the L3Out external EPG. The mgmt EPG provides common/mgmt-ltraci-2143; this YAML does not name a consumer. The two common/ contracts are referenced, not defined here.

Defined in the demo-guide YAMLReferenced, not defined in this YAML
Referenced, not defined in this YAML. These names appear as references in the model (or in a demo step) but have no defining stanza here, so they are drawn as warning boxes and are not invented: ext_epg k8s-epg, contract web-ltraci-2143, contract mgmt-ltraci-2143.

The Multi-Site orchestrator demo step also mentions the DC1 VMM domain clemea-rsite-dc1; that object is not in this YAML and is not drawn.
