ACI architect view

The left half is the tenant model. The right half is the access-policy chain that places those EPGs onto leaf ports. The dashed orange fvRsDomAtt curves are the join between the two halves. Each box jumps to its test rows.

Lessons from APIC 6.0(2h) that this suite encodes
  • Relations in the same POST must be created,modified. The v3 push was rejected with APIC error 102 (HTTP 400, object not found) on infraRsVlanNs RN rsvlanNs, because that relation was sent with status=modified while its parent physical domain was being created in the same POST. v4 changed 14 such relations to created,modified. Existing containers uni/infra and uni/infra/funcprof correctly keep modified.
  • infraNodeBlk uses from_ and to_ (with underscores). from / to is rejected on this release. All four leaf node blocks in the v4 payload use from_/to_.
  • Do not send resImedcy on fvRsPathAtt. That attribute is not valid here on 6.0(2h). The four path attachments omit it and use created,modified.
