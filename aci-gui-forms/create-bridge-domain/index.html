Create Bridge Domain

Create aci_p01_bd_web (subnet 10.0.144.1/29 Advertised Externally, Associated L3 Out aci_p01_L3out) and aci_p01_bd_app (subnet 172.16.1.1/24 Private to VRF) in tenant aci_p01_tenant, VRF aci_p01_vrf. Values are taken only from Aung's unique screenshots; three duplicate files are not shown twice. Step 3 Advanced/Troubleshooting appears only in the app BD sequence.

This page follows the Create Subnet and Create L3Out layout: each of Aung's unique screenshots sits beside an HTML replica of the same window or dialog. Values are taken only from those screenshots. Thirteen files were supplied as step1.png through step13.png; three are byte-identical to earlier shots (step7.png = step1.png, step6.png = step5.png, step10.png = step9.png) and are not shown twice. The files are presented in wizard order, which is not the same as the file numbers (the Create Subnet dialogs are step4.png and step11.png; Step 3 Advanced/Troubleshooting is step13.png and appears only in the app BD sequence).

Two bridge domains are created in tenant aci_p01_tenant, VRF aci_p01_vrf: aci_p01_bd_web with subnet 10.0.144.1/29 (Advertised Externally) and Associated L3 Out aci_p01_L3out, then aci_p01_bd_app with subnet 172.16.1.1/24 (Private to VRF) and no associated L3Out. Both have Unicast Routing and ARP Flooding enabled and MAC Address 00:22:BD:F8:19:FF.

Open Create Bridge Domain

APIC (DC3) Tenants, Tenant Search aci_p01_tenant, Networking, right-click Bridge Domains, Create Bridge Domain. The Bridge Domains table is empty. The same image was also supplied as step7.png and is not repeated.

NaC YAML

apic:
  tenants:
    - name: aci_p01_tenant
      bridge_domains:
        - name: aci_p01_bd_web
          vrf: aci_p01_vrf
          # Unicast Routing and ARP Flooding were both Enabled
          # Config BD MAC Address was ticked
          mac: "00:22:BD:F8:19:FF"
          subnets:
            - ip: 10.0.144.1/29
              # Scope: Advertised Externally (public); Shared between VRFs unticked
              # Subnet Control: ND RA Prefix ticked
              public: true
              private: false
              shared: false
          l3outs:
            - aci_p01_L3out
        - name: aci_p01_bd_app
          vrf: aci_p01_vrf
          mac: "00:22:BD:F8:19:FF"
          subnets:
            - ip: 172.16.1.1/24
              # Scope: both boxes unticked — row then shows Private to VRF
              public: false
              private: true
              shared: false
          # Associated L3 Outs was left empty
