address/mask. Becomes fvSubnet ip. With unicast routing on the BD this is the anycast gateway (SVI) on every leaf where the BD is deployed. NaC ip.

Unchecked. fvSubnet virtual; used for a shared virtual IP (e.g. stretched / multi-site) rather than a per-BD gateway. NaC virtual.

Unchecked. fvSubnet preferred; the primary address is used as the source for things like ARP gleaning when a BD has several subnets. NaC primary_ip.

Advertised Externally

Shared between VRFs

fvSubnet scope. Advertised Externally (checked) means public: the prefix can be advertised out an L3Out. Shared between VRFs (unchecked) means shared: leak to another VRF. With neither box checked the subnet is private to the VRF. NaC public / shared.

optional
No Default SVI Gateway

Querier IP

fvSubnet ctrl. No Default SVI Gateway (no-default-gateway) keeps the subnet without an SVI, for example for a host-route-only design. Querier IP (querier) makes this address the IGMP querier. NaC no_default_gateway / igmp_querier.

DisabledEnabled

Enabled. fvSubnet ipDPLearning. When disabled, the fabric stops learning endpoint IPs from data-plane traffic for this subnet (often used with firewall clusters or floating IPs). NaC ip_dataplane_learning on the subnet (the local schema has it on both bridge_domains and subnets).

Older vs newer APIC version. The older Create Subnet dialog this page first described had a Private to VRF scope option, plus ND RA Prefix and L3 Out for Route Profile / Route Profile. This newer version (Aung's screenshot) drops Private to VRF: a subnet with neither scope box checked is private. It adds IP Data-plane Learning, Subnet Control → No Default SVI Gateway and Policy Tags, and greys out ND RA Prefix Policy for IPv4.

NaC YAML for this exact example

Keys checked against the local Cisco NaC module (terraform-aci-bridge-domain subnets): ip, public, shared, virtual, primary_ip, no_default_gateway, igmp_querier, nd_ra_prefix_policy, ip_dataplane_learning, tags.

YAML
apic:
  tenants:
    - name: TenantA
      bridge_domains:
        - name: TenantA_BD
          vrf: TenantA_VRF
          unicast_routing: true
          subnets:
            - ip: 192.168.6.254/24
              public: true                 # Scope: Advertised Externally (checked)
              shared: false                # Scope: Shared between VRFs (unchecked)
              virtual: false               # Treat as virtual IP address (unchecked)
              primary_ip: false            # Make this IP address primary (unchecked)
              no_default_gateway: false    # Subnet Control: No Default SVI Gateway
              igmp_querier: false          # Subnet Control: Querier IP
              ip_dataplane_learning: true  # IP Data-plane Learning: Enabled
              # l3out for route profile / nd_ra_prefix_policy left unset,
              # as in the screenshot (ND RA Prefix Policy greyed out).
