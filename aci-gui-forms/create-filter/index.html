Create Filter

vzFilter and vzEntry: EtherType, protocol and ports that a contract subject can permit or deny.

GUI: Tenants > {tenant} > Contracts > Filters > Create FilterClass vzFilter / vzEntry

A filter is a named list of entries. A contract subject then permits or denies those filters. Filters in tenant common (arp, default, icmp, est) are available to every tenant.

Recipe steps

  1. Open the tenant, Contracts > Filters, and choose Create Filter.
  2. Name the filter and add one entry per traffic rule (EtherType, protocol, ports, stateful).
  3. Submit, then attach the filter to a contract subject (permit or deny).

NaC YAML

Keys checked against the local Cisco NaC filter module: name, description, entries[].ethertype, protocol, source_from_port, destination_from_port, stateful.

YAML
apic:
  tenants:
    - name: TenantA
      filters:
        - name: allow-https
          description: TCP 443
          entries:
            - name: tcp-443
              ethertype: ip            # vzEntry etherT (ip | ipv4 | arp | ...)
              protocol: tcp            # vzEntry prot
              source_from_port: unspecified
              destination_from_port: https
              destination_to_port: https
              stateful: false
