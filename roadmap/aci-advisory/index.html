Services

1. ACI architecture and solution design

Work on how an ACI fabric is structured: the leaf-and-spine topology, APIC placement, tenants, and how the fabric is intended to connect to workloads and the rest of the network, using Cisco’s published architecture and design guidance.

  1. Cisco Application Centric Infrastructure (ACI) Design Guide
  2. Cisco ACI Fundamentals, Release 6.0(x)

2. HLD and LLD preparation

Preparation of high-level and low-level design documents for an ACI fabric — topology, policy constructs, connectivity and scale — using Cisco’s design guidance and the verified scalability limits published for the relevant APIC and switch releases. Cisco does not publish a product named HLD or LLD; those terms describe the design documents themselves.

  1. Cisco Application Centric Infrastructure (ACI) Design Guide
  2. Verified Scalability Guide for Cisco APIC, Release 6.2(1), 6.2(2), and 6.2(3)

3. Design review and validation

Review of a proposed ACI design against Cisco’s design guidance and the verified scalability limits published for the APIC and ACI-mode switch releases in use.

  1. Cisco Application Centric Infrastructure (ACI) Design Guide
  2. Verified Scalability Guide for Cisco APIC, Release 6.2(1), 6.2(2), and 6.2(3)

4. Fabric implementation support

Support during initial fabric bring-up: APIC cluster setup, switch discovery and registration, and the early configuration steps documented in Cisco’s getting-started and initial-deployment material.

  1. Cisco APIC Getting Started Guide, Release 6.2(x) — Fabric initialization and switch discovery
  2. Setting Up an ACI Fabric: Initial Setup Configuration Example

5. Migration planning

Planning how an existing (brownfield) network and its workloads move to an ACI fabric, including interconnecting the existing network and mapping familiar constructs such as VLANs to ACI objects, as described in Cisco’s migration guidance. Where Nexus 9000 switches themselves move from NX-OS to ACI mode, Cisco also documents POAP auto-conversion.

  1. Migrating Existing Networks to Cisco ACI
  2. Cisco APIC Getting Started Guide, Release 6.2(x) — Cisco NX-OS to Cisco ACI POAP auto-conversion

6. Knowledge transfer

A structured walkthrough of the implemented fabric, using official Cisco documentation and official training — including ACI Fundamentals and Implementing Cisco Application Centric Infrastructure (DCACI) — so operators can work from the same published material.

  1. Cisco ACI Fundamentals, Release 6.0(x)
  2. Implementing Cisco Application Centric Infrastructure (DCACI)

7. Post-implementation handholding

Operational support after the fabric is in service: routine APIC and switch operations, management connectivity, and day-2 tasks covered in Cisco’s system-management and fundamentals documentation.

  1. Cisco APIC System Management Configuration Guide, Release 6.2(x) — Basic Operations
  2. Cisco ACI Fundamentals, Release 6.2(x) — Networking and Management Connectivity

8. Troubleshooting and operational support

Diagnosis of fabric and APIC issues using Cisco’s published troubleshooting tools and guides. The APIC Troubleshooting Guide cited here is the Release 4.2(x) book; the troubleshooting wizard is documented in the Release 6.2(x) Basic Configuration Guide.

  1. Cisco APIC Troubleshooting Guide, Release 4.2(x)
  2. Cisco APIC Basic Configuration Guide, Release 6.2(x) — Using the troubleshooting wizard
