Study notes

Application profiles

An application profile (class fvAp) is a container for EPGs that belong together, for example the tiers of one application. It does not by itself provide connectivity; EPGs, BDs and contracts do.

Example DN: uni/tn-Example-Tenant/ap-Example-AP. Ansible: aci_ap.

APIC GUI path

Tenants → Example-Tenant → Application Profiles.

Common pitfalls
  • Creating many application profiles with no policy reason, or stuffing unrelated EPGs into one profile only because the wizard started there. Either can be valid; be consistent so contracts and operations stay readable.
