ACI GUI Forms & Live Ansible YAML Generator

v2 · 26 Nov 2026, 12:06 PM AEDT

Browser-only Cisco APIC GUI-style forms that live-generate ready-to-run cisco.aci Ansible YAML playbooks as you type. Every section includes an interactive object-hierarchy tree map (click any node to jump to its form), an APIC GUI click-order checklist, copy/download YAML controls, a live Before-Push inspection bar (Change data, simulated --check --diff preview, and NetBox 4.x sync payload), and a CI/CD workflow pack.

Offline & credential-safe by design: All form rendering and YAML generation run locally in your browser. This page never contacts an APIC. Generated playbooks always emit Ansible vault/inventory placeholders (host: "{{ apic_host }}", username: "{{ apic_username }}", password: "{{ apic_password }}") and use RFC 5737 documentation IP addresses by default.

1. Initial Setup

Day-0/Day-1 fabric bring-up: node registration, out-of-band/inband management addressing, NTP/DNS/date-time policies, MP-BGP Route Reflector, VLAN pools, domains, AAEP, interface policies, leaf interface profiles, and switch profiles.

Object Hierarchy Tree Map — Initial Setup

Click any node box below to jump to and highlight its form.

Step-by-Step APIC GUI Order — Initial Setup

  1. 1.1 Register Leaf & Spine Nodes: Fabric → Inventory → Fabric Membership → Nodes Pending Registration.
  2. 1.2 Assign OOB / Inband Management Addresses: Tenants → mgmt → Node Management EPGs & Node Management Addresses.
  3. 1.3 Configure NTP, Date/Time Format & Pod Policy Group: Fabric → Fabric Policies → Policies → Pod → Date and Time and Pods → Policy Groups.
  4. 1.4 Configure DNS Profile & Providers: Fabric → Fabric Policies → Policies → Global → DNS Profiles.
  5. 1.5 Define MP-BGP Route Reflector ASN, Spines & Pod Policy Group: System → System Settings → BGP Route Reflector.
  6. 1.6 Create VLAN Pools & Encap Blocks: Fabric → Access Policies → Pools → VLAN.
  7. 1.7 Create Physical / L3 Domains & Attach VLAN Pool: Fabric → Access Policies → Physical and External Domains.
  8. 1.8 Create AAEP & Bind Domains: Fabric → Access Policies → Policies → Global → Attachable Access Entity Profiles.
  9. 1.9 Create Interface Policies (CDP, LLDP, Link Level, LACP): Fabric → Access Policies → Policies → Interface.
  10. 1.10 Bundle into Leaf Access / vPC Interface Policy Group: Fabric → Access Policies → Interfaces → Leaf Interfaces → Policy Groups.
  11. 1.11 Create Leaf Interface Profile & Port Selector: Fabric → Access Policies → Interfaces → Leaf Interfaces → Profiles.
  12. 1.12 Create Leaf Switch Profile & Link Interface Profile: Fabric → Access Policies → Switches → Leaf Switches → Profiles.

2. BAU Operations

Day-2 tenant provisioning: Tenant, VRF, Bridge Domain with SVI subnet, Application Profile, EPG, Domain attachment, Static Path Binding (access/PC/vPC), Filters, Contracts, Provider/Consumer bindings, and L3Out external connectivity.

Object Hierarchy Tree Map — BAU Operations

Click any node box below to jump to and highlight its form.

Step-by-Step APIC GUI Order — BAU Operations

  1. Create Tenant & VRF: Tenants → Add Tenant → Networking → VRFs → Create VRF.
  2. Create Bridge Domain & Anycast Gateway Subnet: Tenants → [Tenant] → Networking → Bridge Domains → Create Bridge Domain.
  3. Create Application Profile, EPG & Domain Association: Tenants → [Tenant] → Application Profiles → Application EPGs → Domains.
  4. Deploy Static Path Binding (VLAN Encap): EPG → Static Ports → Deploy Static EPG on PC, VPC, or Interface.
  5. Create Filter & Contract with Subject: Tenants → [Tenant] → Contracts → Filters then Standard Contracts.
  6. Bind Contract as Provided / Consumed on EPGs: EPG → Contracts → Add Provided / Consumed Contract.
  7. Build L3Out (Node Profile, Interface Profile, External EPG): Tenants → [Tenant] → Networking → L3Outs (and associate BD to L3Out for route advertisement).

3. Monitoring Policies

Telemetry and alerting policies: Syslog destination groups & sources, SNMP policy & client groups, NetFlow records/exporters/monitors, fault/event retention & EPG monitoring policies, health score weights, and Callhome basics.

Object Hierarchy Tree Map — Monitoring Policies

Click any node box below to jump to and highlight its form.

Step-by-Step APIC GUI Order — Monitoring Policies

  1. Create Syslog Destination Group & Source: Admin → External Data Collectors → Monitoring Destinations → Syslog then Fabric → Fabric Policies → Policies → Monitoring → Common Policy → Callhome/SNMP/Syslog → Syslog.
  2. Configure SNMP Pod Policy & Client Group: Fabric → Fabric Policies → Policies → Pod → SNMP (attach to Pod Policy Group if non-default).
  3. Build NetFlow Record, Exporter & Monitor: Tenants → [Tenant] → Policies → NetFlow (attach Monitor to BD or Interface Policy).
  4. Tune Fault Lifecycle & Tenant Monitoring Policy: Fabric → Fabric Policies → Policies → Monitoring → Common Policy or Tenants → [Tenant] → Policies → Monitoring.
  5. Set Health Score Weights: Fabric → Fabric Policies → Policies → Monitoring → Common Policy → Health Score Evaluation Policy.
  6. Configure Callhome Destination & SMTP Server: Admin → External Data Collectors → Monitoring Destinations → Callhome.

4. Troubleshooting Policies

Packet capture and diagnostic tooling: Access/Fabric/Tenant SPAN & ERSPAN, Atomic Counters, Endpoint Tracker read-only queries, iTraceroute, Troubleshooting Sessions, and Faults/Audit/Event log queries.

Object Hierarchy Tree Map — Troubleshooting Policies

Click any node box below to jump to and highlight its form.

Step-by-Step APIC GUI Order — Troubleshooting Policies

  1. Create SPAN Destination & Source Groups: Fabric → Access Policies / Fabric Policies → Policies → Troubleshooting → SPAN or Tenants → [Tenant] → Policies → Troubleshooting → SPAN.
  2. Enable Atomic Counters (NTP required): Tenants → [Tenant] → Policies → Troubleshooting → Atomic Counters, then inspect Operations → Atomic Counters.
  3. Verify Endpoint Learning & Leaf/vPC Path: Operations → Endpoint Tracker (search by IP, MAC, or Tenant/EPG).
  4. Run iTraceroute Path Probe: Tenants → [Tenant] → Policies → Troubleshooting → Endpoint-to-Endpoint Traceroute Policies.
  5. Launch On-Demand Troubleshooting Session: Operations → Troubleshooting Wizard.
  6. Audit Active Faults, Changes & Events: System → Faults, System → Audit Logs, and System → Events.

5. Service Graphs

L4-L7 firewall and ADC insertion using cisco.aci L4-L7 modules: Logical & Concrete Devices with cluster interfaces, Service Graph Templates with function nodes, Policy-Based Redirect (PBR) with optional IP SLA health groups, Device Selection Policies, and Contract Subject attachment.

Object Hierarchy Tree Map — Service Graphs

Click any node box below to jump to and highlight its form.

Step-by-Step APIC GUI Order — Service Graphs

  1. 5.1 Create L4-L7 Logical Device, Concrete Device & Cluster Interfaces: Tenants → [Tenant] → Services → L4-L7 → Devices.
  2. 5.2 Build Service Graph Template & Function Node: Tenants → [Tenant] → Services → L4-L7 → Service Graph Templates.
  3. 5.3 Create IP SLA, Health Group & PBR Redirect Policy: Tenants → [Tenant] → Policies → Protocol → L4-L7 Policy-Based Redirect.
  4. 5.4 Configure Device Selection Policy & Logical Interface Contexts: Tenants → [Tenant] → Services → L4-L7 → Device Selection Policies.
  5. 5.5 Apply Service Graph Template to Contract Subject: Tenants → [Tenant] → Contracts → Standard → [Contract] → Subjects (and bind consumer/provider EPGs).
  6. 5.6 Verify Deployed Graph Instance & PBR Destinations: Tenants → [Tenant] → Services → L4-L7 → Deployed Graph Instances.

6. Shared L3Out in Tenant common

Shared WAN/border connectivity in tenant: common consumed by user tenants (Tenant A / Tenant B): shared VRF & BD-in-common patterns, BGP/OSPF L3Out in common, External EPG with shared-rtctrl / shared-security subnet flags, global-scoped contracts, and user-tenant BD/EPG consumption.

Object Hierarchy Tree Map — Shared L3Out in Tenant common

Click any node box below to jump to and highlight its form.

Step-by-Step APIC GUI Order — Shared L3Out in Tenant common

  1. 6.1 Configure Shared VRF & Optional BD-in-common: Tenants → common → Networking → VRFs / Bridge Domains.
  2. 6.2 Create L3Out in Tenant common (BGP or OSPF): Tenants → common → Networking → L3Outs (node profile, interface profile, routed SVI/subinterface, peer/OSPF policy).
  3. 6.3 Create External EPG with Shared Route Control & Shared Security Subnets: External EPGs → Subnets → Scope: Shared Route Control + Shared Security Import + Import Security.
  4. 6.4 Create Global Contract in common & Provide on External EPG: Tenants → common → Contracts → Standard (Scope: Global), optionally export vz:CPIf.
  5. 6.5 Set User Tenant BD Subnet to Advertised Externally + Shared & Associate Common L3Out: Tenants → [User Tenant] → Networking → Bridge Domains → [BD].
  6. 6.6 Consume the Global Contract from User Tenant EPG: Tenants → [User Tenant] → Application Profiles → [AP] → EPGs → Contracts → Add Consumed Contract.
