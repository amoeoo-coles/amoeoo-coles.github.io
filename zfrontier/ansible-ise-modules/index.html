Ansible Cisco ISE Module Catalogue

v1 · 26 Nov 2026, 9:05 PM AEDT

Every module in the cisco.ise Ansible collection (3.3.0, 252 modules), read from the installed collection’s DOCUMENTATION and EXAMPLES. Each module has a YAML model with a references block and a numbered sample playbook, in ISE build order: deployment and nodes, certificates, identity stores, network devices, policy elements, device administration, TrustSec, guest and portals, integrations, then operations.

Credential-safe by design: This page is a static catalogue and never contacts a controller. Connection options use the placeholders {{ ise_hostname }} {{ ise_username }} {{ ise_password }} from inventory.yml, and every password, key, token or community value in a model is a {{ vault_… }} placeholder. Every module that can change state is tagged never in its playbook, so site.yml runs only read-only modules unless you ask for a tag.

Files, models and samples

All 252 items are published as real files, plus combined files and a single sample data model.

  • site.yml: combined playbook that imports every playbook in build order (state-changing plays are tagged never)
  • sample/ise-model.yml: combined sample data model
  • inventory.yml and ansible.cfg: placeholders only
  • playbooks/filter_plugins/cat_model.py: null-stripping filter used by every playbook
  • models/<module>.yml: one model per item, each opening with a references block
  • playbooks/<NNNN>_<module>.yml: one numbered sample playbook per item

Syntax-check locally with the collection installed:

ansible-galaxy collection install cisco.ise:3.3.0
ansible-playbook --syntax-check -i inventory.yml site.yml
# Read-only run (info modules only; every state-changing play is tagged never):
ansible-playbook -i inventory.yml site.yml
