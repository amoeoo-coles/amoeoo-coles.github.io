Ansible cisco.mso Module Catalogue

v1 · 26 Nov 2026, 20:52 AEDT

Every module in the cisco.mso Ansible collection (3.0.0, 135 modules), taken from the installed collection’s DOCUMENTATION and EXAMPLES. Each module has its own YAML data model and a sample playbook that reads that model with vars_files. Playbooks are numbered in chronological MSO/NDO build order: platform and sites, tenants, schema and templates, VRF, bridge domains, ANP/EPG, contracts and external EPGs, L3Out, service graphs, tenant policy templates, fabric policy and resource templates, then validate, deploy and utility modules. Option names, types, choices and required flags are only those documented by the collection. Nothing here is invented. Deprecated modules are marked.

Credential-safe by design: This page is a static catalogue. It never contacts an MSO or Nexus Dashboard Orchestrator. Inventory, models and playbooks use only the placeholders {{ mso_host }}, {{ mso_username }} and {{ mso_password }}. Addresses use documentation and example ranges. Do not commit real passwords. A live ansible-playbook run belongs on a self-hosted runner that can reach your orchestrator.

Playbooks, models and inventory

All 135 models and playbooks are published as real files, plus a combined playbook and a single sample data model.

  • Combined end-to-end playbook: site.yml (imports every playbook in build order)
  • Combined sample data model: sample/mso-model.yml
  • Inventory example: inventory.yml with placeholders {{ mso_host }} {{ mso_username }} {{ mso_password }}
  • Per-module models: models/<module>.yml
  • Per-module playbooks: playbooks/<NNN>_<module>.yml

Syntax-check locally with the collection installed:

ansible-galaxy collection install cisco.mso:3.0.0
ansible-playbook --syntax-check -i inventory.yml site.yml \
  -e mso_host=ndo.example.com -e mso_username=admin -e mso_password=placeholder
