Hyperfabric - Select and Stage VNI Port Memberships

v1 · 22 Nov 2026, 1:37 AM AEDT

Detail for Hyperfabric - Select and Stage VNI Port Memberships, in the Other group.

Description

Discover and select up to 20 fabrics, then choose each fabric's VNIs, enabled switches, and eligible HOST_PORT interfaces. Exclude existing VNI members, preview tagged or untagged payloads, default to Dry Run, and require APPLY per fabric. Before staging, require a clean candidate and complete candidate history; block only when the latest returned maintenance transition explicitly reports CANDIDATE_MAINTENANCE_ON. Missing maintenance history does not block APPLY; it is reported as UNKNOWN. Stage into the default candidate only; never commit. Output Status is Success with no failures, Partial when some staging succeeds and another fabric operation fails or is blocked, and Failed when all staging is blocked or fails. Per-fabric outcomes remain in Result. Requires a Nexus Hyperfabric endpoint target.
