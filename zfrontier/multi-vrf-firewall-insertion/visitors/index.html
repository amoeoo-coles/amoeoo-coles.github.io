Multi-VRF Firewall Insertion · visitor tracking

v3 · 26 Nov 2026, 8:36 PM AEDT

This hidden view reuses the site’s existing visitor pipeline only: the visitor badge, GoatCounter page counts, and the already-deployed country/ISP event mechanism. It does not add a new geolocation or analytics service, and it never publishes visitor IP addresses.

A per-visit table with time, page, country, ISP and a masked IP is not collected. GoatCounter and the published JSON files store aggregates only. Visitor IPs are sent only to the existing lookup (geojs.io, with ipwho.is as fallback) when the ISP event script runs, and are never stored here or sent to GoatCounter. Past visits cannot be backfilled.

The visitor-stats workflow runs about hourly (GitHub Actions at minute 7 and 37, best-effort) and writes /data/visitors.json. This page also reads data.json in this folder, when present, and /visitors/detail.json for hourly page totals. Figures below are unique visitors per page per Melbourne day (or hour, where noted).

The columns requested for this view are time (AEDT), page, country, ISP and masked IP. The existing pipeline cannot fill country, ISP or IP on a per-visit or per-page-hour row. Not collected

  • Per-visit timestamps (only daily or hourly aggregates are published).
  • Country or ISP for a specific visit to a page under this prefix.
  • Visitor IP addresses, including masked IPs — they are never stored in this pipeline.
  • Prefix-specific ISP totals (ISP events are site-wide and are not tagged with this page path).
  • Prefix-specific country totals, unless the visitor-stats workflow receives a path-filtered locations result for this prefix.
