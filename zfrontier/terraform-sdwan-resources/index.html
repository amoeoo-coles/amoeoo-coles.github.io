Terraform Cisco SD-WAN Resource Catalogue

v1 · 26 Nov 2026, 9:05 PM AEDT

Every resource and data source in the CiscoDevNet/sdwan Terraform provider (0.12.0: 276 resources and 273 data sources) for Cisco Catalyst SD-WAN, taken from the provider schema and the registry docs at the same tag. Each item has a YAML data model whose keys are exactly the schema inputs, and a numbered sample .tf that reads the model with yamldecode(file(...)), in build order: settings and users, network hierarchy, policy objects, feature profiles and features, configuration and policy groups, then the classic templates and policies. Values come only from the docs Example Usage, otherwise null; references to other objects are REPLACE_ME. Nothing here is invented. Group 14 adds the netascode terraform-sdwan-nac-sdwan Network-as-Code module: its inputs and outputs, its YAML data model sections, and a sample nac/main.tf with nac/data/*.nac.yaml files in build order (18 items).

Credential-safe by design: This page is a static catalogue and never contacts a controller. Provider credentials come only from variables (var.sdwan_url var.sdwan_username var.sdwan_password); every sensitive or secret-like attribute in a model is a {{ attribute_name }} placeholder. main.tf is for terraform validate only: it declares every object type with REPLACE_ME placeholders, so never apply it as-is.

Files, models and samples

All 567 items are published as real files, plus combined files and a single sample data model.

  • providers.tf, variables.tf and terraform.tfvars.example: provider block and variables (placeholders only)
  • main.tf: combined config that loads every file in tf/ as one module, for terraform validate
  • sample/sdwan-model.yml: combined sample data model
  • models/<name>.yml: one YAML model per resource or data source (data sources are prefixed data_)
  • tf/<NNN>_<name>.tf: one numbered sample .tf per item that reads its model with yamldecode(file(...))
  • nac/main.tf and nac/data/NN_<section>.nac.yaml: sample root module and data files, in build order, for the netascode terraform-sdwan-nac-sdwan module (group 14)

Validate locally (no credentials needed):

terraform init -backend=false
terraform validate
# Pick the tf/NNN_*.tf files you need with their models/*.yml, fill the values, then plan.

Page: Terraform Cisco SD-WAN Resource Catalogue · Version: v1 · 26 Nov 2026, 9:05 PM AEDT

Provider: CiscoDevNet/sdwan 0.12.0 (276 resources, 273 data sources), the latest on the Terraform Registry on 26 Nov 2026. Attributes come from terraform providers schema -json for that exact version; descriptions, subcategories and sample values from the docs Example Usage in the provider repository at tag v0.12.0. Groups follow the docs subcategory, in build order; inside a group, objects referenced by other objects’ examples come first. Deprecated items are marked where the schema or docs say so. The Network-as-Code section (group 14) comes from netascode/terraform-sdwan-nac-sdwan at commit 5c49bbf (main, 25 Nov 2026 UTC), which requires sdwan ~> 0.12.0; its latest release v1.5.1 still pins ~> 0.11.7. Inputs and outputs are from its README; the data model structure is from nac/schema.yaml; the only literal sample values upstream are the banner template example.

Folder links end with /. Credentials are placeholders only (var.sdwan_url var.sdwan_username var.sdwan_password). Addresses are documentation ranges only (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24); other example addresses copied from upstream docs were moved into those ranges. No live device or controller was contacted; device output is not collected.
