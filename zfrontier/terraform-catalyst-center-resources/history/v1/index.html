Terraform Cisco Catalyst Center Resource Catalogue

v1 · 26 Nov 2026, 9:05 PM AEDT

Every resource and data source in the CiscoDevNet/catalystcenter Terraform provider (0.6.9: 108 resources and 88 data sources) for Cisco Catalyst Center, taken from the provider schema and the registry docs at the same tag. Each item has a YAML data model whose keys are exactly the schema inputs, and a numbered sample .tf that reads the model with yamldecode(file(...)), in build order: system, sites, network settings and tags, discovery and PnP, SWIM, templates and profiles, SD-Access, wireless, then application policy. Values come only from the docs Example Usage, otherwise null; references to other objects are REPLACE_ME. Nothing here is invented.

Credential-safe by design: This page is a static catalogue and never contacts a controller. Provider credentials come only from variables (var.catalystcenter_url var.catalystcenter_username var.catalystcenter_password); every sensitive or secret-like attribute in a model is a {{ attribute_name }} placeholder. main.tf is for terraform validate only: it declares every object type with REPLACE_ME placeholders, so never apply it as-is.

Files, models and samples

All 196 items are published as real files, plus combined files and a single sample data model.

  • providers.tf, variables.tf and terraform.tfvars.example: provider block and variables (placeholders only)
  • main.tf: combined config that loads every file in tf/ as one module, for terraform validate
  • sample/catalystcenter-model.yml: combined sample data model
  • models/<name>.yml: one YAML model per resource or data source (data sources are prefixed data_)
  • tf/<NNN>_<name>.tf: one numbered sample .tf per item that reads its model with yamldecode(file(...))

Validate locally (no credentials needed):

terraform init -backend=false
terraform validate
# Pick the tf/NNN_*.tf files you need with their models/*.yml, fill the values, then plan.

Provider: CiscoDevNet/catalystcenter 0.6.9 (108 resources, 88 data sources), the latest on the Terraform Registry on 26 Nov 2026. Attributes come from terraform providers schema -json for that exact version; descriptions, subcategories and sample values from the docs Example Usage in the provider repository at tag v0.6.9. Groups follow the docs subcategory, in build order; inside a group, objects referenced by other objects’ examples come first. Deprecated items are marked where the schema or docs say so.

Folder links end with /. Credentials are placeholders only (var.catalystcenter_url var.catalystcenter_username var.catalystcenter_password). Addresses are documentation ranges only (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24); other example addresses copied from upstream docs were moved into those ranges. No live device or controller was contacted; device output is not collected.
