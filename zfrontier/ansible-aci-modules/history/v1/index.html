Ansible cisco.aci Module Catalogue

v1 · 26 Nov 2026, 5:00 PM AEDT

Every module in the cisco.aci Ansible collection (3.0.0, 287 modules), taken from the installed collection’s DOCUMENTATION and EXAMPLES. Each module has its own YAML data model and a sample playbook that reads that model with vars_files. Playbooks are numbered in chronological fabric build order, from system and access policies through tenant networking, applications, L4–L7 service graphs, Multi-Pod / Remote Leaf / Cloud, monitoring, and operational utilities. Option names, types, choices and required flags are only those documented by the collection. Nothing here is invented.

Credential-safe by design: This page is a static catalogue. It never contacts an APIC. Inventory, models and playbooks use only the placeholders {{ apic_host }}, {{ apic_username }} and {{ apic_password }}. Addresses use documentation and example ranges. Do not commit real passwords. A live ansible-playbook run belongs on a self-hosted runner that can reach your APIC.

Playbooks, models and inventory

All 287 models and playbooks are published as real files, plus a combined playbook and a single sample data model.

  • Combined end-to-end playbook: site.yml (imports every playbook in build order)
  • Combined sample data model: sample/aci-model.yml
  • Inventory example: inventory.yml with placeholders {{ apic_host }} {{ apic_username }} {{ apic_password }}
  • Per-module models: models/<module>.yml
  • Per-module playbooks: playbooks/<NNN>_<module>.yml

Syntax-check locally with the collection installed:

ansible-galaxy collection install cisco.aci
ansible-playbook --syntax-check -i inventory.yml site.yml \
  -e apic_host=apic.example.com -e apic_username=admin -e apic_password=placeholder
