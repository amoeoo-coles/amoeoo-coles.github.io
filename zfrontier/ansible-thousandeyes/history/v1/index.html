Ansible ThousandEyes API Catalogue (uri, unofficial)

v1 · 26 Nov 2026, 9:05 PM AEDT

Not an official collection. There is no ThousandEyes collection on Ansible Galaxy, so this page drives the ThousandEyes API v7 with Ansible’s built-in ansible.builtin.uri module. It has one item per API class (95 items, 312 endpoints) taken from ThousandEyes’ official thousandeyes-sdk-python docs (commit ad7fe76, 13 Nov 2026). Each item has a YAML model listing its documented endpoints, path parameters and the writable JSON fields of its create body, plus a numbered sample playbook that lists the resource with GET and (tagged never) creates it with POST. Build order: account groups and users, credentials, agents, tags, tests, alerts, dashboards, endpoint agents and tests, instant tests, results, BGP, events, Internet Insights, snapshots, emulation, connectors and usage.

Credential-safe by design: the bearer token is the placeholder {{ te_token }} (inventory points it at {{ vault_te_token }}). This page never calls the API. Every POST task is tagged never, so site.yml only reads unless asked.

Files, models and samples

All 95 items are published as real files, plus combined files and a single sample data model.

  • site.yml: combined playbook (GET by default, POST tagged never)
  • sample/thousandeyes-model.yml: combined sample model
  • inventory.yml and ansible.cfg: placeholders only
  • playbooks/filter_plugins/cat_model.py: null-stripping filter
  • models/<api_class>.yml and playbooks/<NNN>_<api_class>.yml

Syntax-check locally (only ansible-core is needed):

ansible-playbook --syntax-check -i inventory.yml site.yml
ansible-playbook -i inventory.yml site.yml -e te_token='***'   # GET only
