Ansible Cisco Catalyst Center Module Catalogue

v1 · 26 Nov 2026, 9:05 PM AEDT

Every module in the cisco.catalystcenter Ansible collection (2.15.0, 1551 modules, info modules included), read from the installed collection’s DOCUMENTATION and EXAMPLES. Each module has a YAML model with a references block (including its API family) and a numbered sample playbook, in build order: system, site hierarchy, network settings, discovery and PnP, SWIM, templates, SD-Access, wired, wireless, application policy, then assurance. Within a group, config modules come first, then workflow managers, then read-only info modules. This is a large page: the index loads once, and cards render group by group as you scroll. cisco.dnac 6.51.0 is the legacy collection this one replaces.

Credential-safe by design: This page is a static catalogue and never contacts a controller. Connection options use the placeholders {{ catalystcenter_host }} {{ catalystcenter_username }} {{ catalystcenter_password }} from inventory.yml, and every password, key, token or community value in a model is a {{ vault_… }} placeholder. Every module that can change state is tagged never in its playbook, so site.yml runs only read-only modules unless you ask for a tag.

Files, models and samples

All 1551 items are published as real files, plus combined files and a single sample data model.

  • site.yml: combined playbook that imports every playbook in build order (state-changing plays are tagged never)
  • sample/catalystcenter-model.yml: combined sample data model
  • inventory.yml and ansible.cfg: placeholders only
  • playbooks/filter_plugins/cat_model.py: null-stripping filter used by every playbook
  • models/<module>.yml: one model per item, each opening with a references block
  • playbooks/<NNNN>_<module>.yml: one numbered sample playbook per item

Syntax-check locally with the collection installed:

ansible-galaxy collection install cisco.catalystcenter:2.15.0
ansible-playbook --syntax-check -i inventory.yml site.yml
# Read-only run (info modules only; every state-changing play is tagged never):
ansible-playbook -i inventory.yml site.yml

Collection: cisco.catalystcenter 2.15.0 (1,551 modules in plugins/modules/, 909 of them read-only _info modules), the latest on Ansible Galaxy on 26 Nov 2026, read with ansible-doc --json. Groups follow the API family named in each module’s seealso link; modules with no API family (mostly workflow managers and config generators) are grouped by name keyword. Official docs: catalystcenter-ansible v2.15.0. cisco.dnac 6.51.0 is the legacy collection for the same product (Cisco DNA Center); it is not listed item by item here (Galaxy, docs).

Folder links end with /. Credentials are placeholders only ({{ catalystcenter_host }} {{ catalystcenter_username }} {{ catalystcenter_password }}). Addresses are documentation ranges only (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24); other example addresses copied from upstream docs were moved into those ranges. No live device or controller was contacted; device output is not collected.
