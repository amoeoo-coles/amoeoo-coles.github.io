📟 MS-02 Ultra + NVIDIA GPU Monitoring (Prometheus & Grafana)

An open-source monitoring stack for the Minisforum MS-02 Ultra and its NVIDIA RTX PRO 2000 Blackwell GPU. It follows Datadog's Cheatsheet: Nvidia DCGM, but collects the same DCGM metrics with NVIDIA's dcgm-exporter, Prometheus and Grafana instead of the Datadog Agent.

Overview

MS-02 UltraUbuntu 26.04.1 LTS · kernel 7.0.0-43 · 14 threads · 247 GiB RAM
RTX PRO 2000Blackwell · 16 GB · 70 W power limit · driver 595.99.02
Docker 29.10.0Compose v5.5.1 · NVIDIA Container Toolkit 1.20.2
4 containers3/3 scrape targets up · 10 alert rules · 22 DCGM fields

Why not Datadog? The cheatsheet is written for Datadog's DCGM integration. Datadog's free tier covers up to 5 hosts with only 1-day metric retention, and Infrastructure starts at US$15 per host per month on an annual plan, with GPU Monitoring sold as a separate add-on (Datadog pricing).

For one workstation, dcgm-exporter exposes the same NVIDIA DCGM fields (the cheatsheet's “NVIDIA name” column) directly to Prometheus. That keeps 30 days of history and alert rules at no cost, and Grafana shows them in community dashboards.

Architecture

All four containers run on the MS-02 itself from one docker-compose.yml. Arrows show the direction data flows.

Configuration

These are the files deployed to ~/gpu-monitoring on the MS-02. The private LAN address is shown as <ms02-ip>. No secrets appear here: Grafana reads its admin password from secrets/grafana_admin_password, a file with mode 600 owned by uid 1000, which is mounted read-only and passed in with GF_SECURITY_ADMIN_PASSWORD__FILE. The container runs as 1000:1000 so it can read the file.

docker-compose.yml docker-compose.yml
# GPU + host monitoring stack for Minisforum MS-02 Ultra (NVIDIA RTX PRO 2000 Blackwell)
# Location on MS-02: ~/gpu-monitoring   Start: docker compose up -d
name: gpu-monitoring

services:
  dcgm-exporter:
    image: nvidia/dcgm-exporter:4.7.0-4.9.0
    container_name: dcgm-exporter
    restart: unless-stopped
    cap_add:
      - SYS_ADMIN            # needed for DCGM profiling (DCGM_FI_PROF_*) metrics
    command: ["-f", "/etc/dcgm-exporter/custom-counters.csv"]
    volumes:
      - ./dcgm/custom-counters.csv:/etc/dcgm-exporter/custom-counters.csv:ro
    ports:
      - "9400:9400"
    deploy:
      resources:
        reservations:
          devices:
            - driver: nvidia
              count: all
              capabilities: [gpu]

  node-exporter:
    image: prom/node-exporter:v1.12.1
    container_name: node-exporter
    restart: unless-stopped
    network_mode: host       # listens on host :9100
    pid: host
    command:
      - --path.rootfs=/host
      - --web.listen-address=:9100
      - --collector.filesystem.mount-points-exclude=^/(dev|proc|sys|run|var/lib/docker/.+|var/lib/containerd/.+|snap/.+)($|/)
    volumes:
      - /:/host:ro,rslave

  prometheus:
    image: prom/prometheus:v3.16.0
    container_name: prometheus
    restart: unless-stopped
    command:
      - --config.file=/etc/prometheus/prometheus.yml
      - --storage.tsdb.path=/prometheus
      - --storage.tsdb.retention.time=30d
      - --web.enable-lifecycle
    extra_hosts:
      - "host.docker.internal:host-gateway"
    volumes:
      - ./prometheus/prometheus.yml:/etc/prometheus/prometheus.yml:ro
      - ./prometheus/rules:/etc/prometheus/rules:ro
      - prometheus-data:/prometheus
    ports:
      - "9090:9090"
    depends_on:
      - dcgm-exporter

  grafana:
    image: grafana/grafana:13.2.6
    container_name: grafana
    restart: unless-stopped
    user: "1000:1000"        # same uid as the owner of the 600 password file
    environment:
      - GF_SECURITY_ADMIN_USER=admin
      - GF_SECURITY_ADMIN_PASSWORD__FILE=/run/secrets/grafana_admin_password
      - GF_USERS_ALLOW_SIGN_UP=false
      - GF_ANALYTICS_REPORTING_ENABLED=false
    volumes:
      - ./secrets/grafana_admin_password:/run/secrets/grafana_admin_password:ro
      - ./grafana/provisioning:/etc/grafana/provisioning:ro
      - ./grafana/dashboards:/var/lib/grafana-dashboards:ro
      - ./grafana-data:/var/lib/grafana
    ports:
      - "3000:3000"
    depends_on:
      - prometheus

volumes:
  prometheus-data:
prometheus.yml prometheus/prometheus.yml

Alert rules prometheus/rules/ms02-alerts.yml
groups:
  - name: gpu-dcgm
    rules:
      - alert: GPUHighTemperature
        expr: DCGM_FI_DEV_GPU_TEMP > 85
        for: 5m
        labels: {severity: critical}
        annotations:
          summary: "GPU {{ $labels.gpu }} temperature {{ $value }}C (> 85C for 5m)"
      - alert: GPUHighUtilization
        expr: DCGM_FI_DEV_GPU_UTIL > 95
        for: 15m
        labels: {severity: warning}
        annotations:
          summary: "GPU {{ $labels.gpu }} utilization {{ $value }}% (> 95% for 15m)"
      - alert: GPUFramebufferNearlyFull
        expr: DCGM_FI_DEV_FB_USED / (DCGM_FI_DEV_FB_USED + DCGM_FI_DEV_FB_FREE) * 100 > 90
        for: 5m
        labels: {severity: warning}
        annotations:
          summary: "GPU {{ $labels.gpu }} framebuffer {{ $value | printf \"%.1f\" }}% used (> 90%)"
      - alert: GPUPowerNearLimit
        expr: DCGM_FI_DEV_POWER_USAGE / DCGM_FI_DEV_POWER_MGMT_LIMIT * 100 > 95
        for: 10m
        labels: {severity: warning}
        annotations:
          summary: "GPU {{ $labels.gpu }} drawing {{ $value | printf \"%.0f\" }}% of its power limit for 10m"
      - alert: GPUXidError
        expr: DCGM_FI_DEV_XID_ERRORS > 0
        for: 0m
        labels: {severity: critical}
        annotations:
          summary: "GPU {{ $labels.gpu }} reported XID error {{ $value }} (check dmesg / NVIDIA XID catalog)"
      - alert: GPUPCIeReplays
        expr: increase(DCGM_FI_DEV_PCIE_REPLAY_COUNTER[10m]) > 0
        for: 0m
        labels: {severity: warning}
        annotations:
          summary: "GPU {{ $labels.gpu }} PCIe replay counter increasing"

  - name: exporters
    rules:
      - alert: ExporterTargetDown
        expr: up == 0
        for: 2m
        labels: {severity: critical}
        annotations:
          summary: "Scrape target {{ $labels.job }} ({{ $labels.instance }}) is down"

  - name: host
    rules:
      - alert: HostHighCPU
        expr: 100 - (avg by (instance) (rate(node_cpu_seconds_total{mode="idle"}[5m])) * 100) > 90
        for: 10m
        labels: {severity: warning}
        annotations:
          summary: "Host CPU {{ $value | printf \"%.1f\" }}% (> 90% for 10m)"
      - alert: HostHighMemory
        expr: (1 - node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes) * 100 > 90
        for: 10m
        labels: {severity: warning}
        annotations:
          summary: "Host RAM {{ $value | printf \"%.1f\" }}% used (> 90%)"
      - alert: HostDiskFull
        expr: (1 - node_filesystem_avail_bytes{fstype!~"tmpfs|overlay|squashfs|ramfs"} / node_filesystem_size_bytes{fstype!~"tmpfs|overlay|squashfs|ramfs"}) * 100 > 85
        for: 10m
        labels: {severity: warning}
        annotations:
          summary: "Disk {{ $labels.mountpoint }} {{ $value | printf \"%.1f\" }}% used (> 85%)"

Caveats and next steps

  • No Alertmanager yet. Alerts only show on http://<ms02-ip>:9090/alerts. Add Alertmanager with an email or chat receiver to get notified.
  • XID errors: DCGM_FI_DEV_XID_ERRORS only appears after the GPU reports an XID, so the GPUXidError rule stays silent until then.
  • No memory temperature: the RTX PRO 2000 does not expose DCGM_FI_DEV_MEMORY_TEMP, so that panel is empty.
  • GPU memory runs close to the 90% alert whenever an LLM is loaded (about 87% with the current LM Studio model). A bigger model will fire GPUFramebufferNearlyFull.
  • Stack lives in the home directory (~/gpu-monitoring) because sudo needs a password. Docker's restart: unless-stopped brings it back after a reboot, as long as the Docker service starts.

Operating

cd ~/gpu-monitoring && docker compose up -d     # start / apply changes
cd ~/gpu-monitoring && docker compose down      # stop (data volume kept)
docker compose ps                                 # status
curl -s localhost:9090/api/v1/targets | jq '.data.activeTargets[].health'
curl -X POST localhost:9090/-/reload              # reload rules after editing
  • Grafana: http://<ms02-ip>:3000 (user admin; password in ~/gpu-monitoring/secrets/grafana_admin_password)
  • Prometheus: http://<ms02-ip>:9090
  • Alerts: http://<ms02-ip>:9090/alerts
