### Purpose

This site demonstrates Infrastructure as Code (IaC) for network provisioning. A single Universal Provisioning request is captured once, stored as the source of truth in NetBox, presented through the Super Portal front end, turned into code by an automated pipeline, approved, and then deployed to the Development and Production environments. Every change is versioned, reviewed and repeatable,…
