## English

### Purpose

Prove the whitelist model with the running VMs. Hosts in the same EPG (the two web servers) can ping each other without a contract. Web-to-app pings work because aci_p01_fil currently allows only ICMP; SSH fails until a TCP/22 entry named ssh is added to that filter. External access to the web server is then checked at http://10.x.x.x/LTRACI-2143.jpg after httpd is started.
