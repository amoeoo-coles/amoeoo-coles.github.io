## English

### Purpose

From ACI 5.0, an Endpoint Security Group is a security zone associated with a VRF rather than a single BD, so it can span BDs. Endpoints join through selectors (for example IP subnets). Members of the same ESG can talk without a contract; different ESGs, and traffic to an L3Out, still need contracts. This loosens the EPG's combination of forwarding and security.
