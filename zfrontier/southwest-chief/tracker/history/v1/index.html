Southwest Chief live tracker

v1 · 24 Nov 2026, 12:37 PM AEDT

Live positions for Amtrak trains 3 (Chicago to Los Angeles) and 4 (Los Angeles to Chicago). When you open this page, your browser asks the Amtraker public API for the current runs and places them on the same rail map as the Southwest Chief planning page. This is not an official Amtrak page. Always verify with Amtrak before you travel.

Live data comes from a third-party service. Train positions and status are from Amtraker (amtraker.com), licensed under the Open Data Commons Attribution License (ODC-By) v1.0. Amtraker says the train data comes from Amtrak. Amtrak and the Amtrak logo are trademarks of the National Railroad Passenger Corporation. Amtraker and this page are not affiliated with, endorsed by, or sponsored by Amtrak. Each visitor's browser connects directly to api.amtraker.com to load and refresh this data. Nothing is invented here: if a field is missing, it is shown as not available.

Live map

The line and station dots are the cached OpenStreetMap Southwest Chief route used on the planning page. The numbered markers are live train 3 and train 4 runs from Amtraker, drawn only when that API returns a position. Click a train for speed, heading, status, the next or current stop, and the last report time.

Loading live positions from Amtraker…

The page refreshes automatically every 90 seconds. A manual refresh will not run more often than every 60 seconds, so the Amtraker API is not requested in a tight loop. Amtraker asks users not to spam the API and does not publish a stricter interval than that.

Active trains

Every run of train 3 and train 4 returned by the API. Late or early minutes are calculated on this page from that run's current or next stop, using the scheduled and estimated or actual times Amtraker returned. They are not an official Amtrak score. Click a column header to sort.

Sources

  • Amtraker public API, current documented v3 endpoints: https://api.amtraker.com/v3/trains/3 and https://api.amtraker.com/v3/trains/4. Documentation: https://api.amtraker.com/docs (redirects to the Amtrak.js / Amtraker README). About page: https://amtraker.com/about.
  • Amtraker Southwest Chief trains on Amtraker.com: train 3 and train 4. Site: https://amtraker.com.
  • Amtraker API data is licensed under ODC-By v1.0. Amtraker asks for prominent attribution linking to amtraker.com, including map credit in the map corner. The train data provider is Amtrak, as stated by Amtraker. Amtrak official route page: https://www.amtrak.com/southwest-chief-train.
  • Route line and station coordinates: the cached OpenStreetMap geometry already used on the Southwest Chief planning page (relation 4720713, ODbL). Map tiles © OpenStreetMap contributors.

Not collected

  • A late-or-early figure when Amtraker does not return both a scheduled time and an estimated or actual time for that stop.
  • Any train other than 3 and 4, and any historical archive (Amtraker historical data is available only by request, which was not made).
  • Official Amtrak ticket or reservation status.
