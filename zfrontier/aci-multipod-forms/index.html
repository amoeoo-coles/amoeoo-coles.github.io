3. Planning & Prerequisites

Lock down non-overlapping TEP pools, External Routable TEPs, VLAN-4 /30 addressing, MTU 9150+ requirements, and COOP/BGP prerequisites before configuring the IPN or APIC.

Object Hierarchy Tree Map — Planning & Prerequisites

Click any box to jump to and highlight its planning form.

Step-by-Step Planning Checklist

  1. 3.1 Reserve non-overlapping Pod TEP pools (10.10.0.0/16 Pod 1, 10.20.0.0/16 Pod 2), per-pod External Routable TEP /24s, and a shared Data-Plane Anycast TEP /32.
  2. 3.2 Allocate VLAN-4 point-to-point subnets between every Spine and IPN Nexus switch, plus a dedicated IPN VRF (ACI-IPN) and Phantom RP address.
  3. 3.3 Verify end-to-end MTU >= 9150 bytes across the IPN (recommended 9216) and confirm RTT <= 50 ms between Pods.

4. Nexus IPN Switch Configs (NX-OS CLI & Ansible cisco.nxos)

Every form below live-generates both an Ansible cisco.nxos YAML playbook and the exact NX-OS CLI configuration block for standalone Nexus 9000 IPN switches.

IPN Architecture Tree Map — Nexus NX-OS

Click any node to jump to its NX-OS CLI + Ansible form.

Step-by-Step Nexus IPN Configuration Order

  1. 4.1 Enable NX-OS features (ospf, pim, interface-vlan, dhcp), set system jumbomtu 9216, and create VRF ACI-IPN.
  2. 4.2 Build Dot1q VLAN-4 subinterfaces toward every ACI Spine with mtu 9150 and no ip redirects.
  3. 4.3 Enable OSPF Area 0 in point-to-point mode across spine subinterfaces and inter-IPN core links.
  4. 4.4 Configure DHCP Relay on Pod 2 spine-facing subinterfaces pointing to Pod 1 APIC Infra TEPs.
  5. 4.5 Configure PIM Bidir & Phantom RP (/30 on IPN-1, /29 on IPN-2) for GIPo range 225.0.0.0/15.
  6. 4.6 Preserve DSCP CS6 QoS markings and validate with 9122-byte DF-bit pings.

5. APIC Multi-Pod Fabric Setup (cisco.aci & aci_rest)

Configure APIC Multi-Pod policies in tenant infra and uni/fabric using dedicated cisco.aci modules and cisco.aci.aci_rest where no dedicated module exists.

Object Hierarchy Tree Map — APIC Multi-Pod Setup

Click any node to jump to its APIC form.

Step-by-Step APIC Multi-Pod Setup Order

  1. 5.1 Define Pod 2 TEP Pool in fabricSetupPol (10.20.0.0/16).
  2. 5.2 Bind Pods 1–2 to a Pod Policy Group via a Pod Profile and Pod Selector.
  3. 5.3 Create the Multi-Pod L3Out in tenant infra (OSPF Area 0, vlan-4 subinterfaces, MTU 9150).
  4. 5.4 Reserve External Routable TEPs and assign Spine Router-ID loopbacks.
  5. 5.5 Configure Fabric External Connection Policy, Data-Plane Anycast TEP, and export Pod TEPs.
  6. 5.6 Designate Pod 1 & Pod 2 Spines as BGP Route Reflectors and enforce COOP Strict mode.
