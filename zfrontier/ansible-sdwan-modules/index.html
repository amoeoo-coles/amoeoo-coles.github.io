Ansible Cisco SD-WAN Module Catalogue

v1 · 26 Nov 2026, 9:05 PM AEDT

Every module in the cisco.catalystwan Ansible collection for Cisco Catalyst SD-WAN Manager (0.3.2, 26 modules), read from the installed collection’s DOCUMENTATION and EXAMPLES. Each module has a YAML model that opens with a references block and a numbered sample playbook that reads it with vars_files, in build order: bootstrap and Manager settings, controllers and edges, software, classic templates, configuration groups, then operations. Keys are only documented options; values come only from the module’s own examples, otherwise null. Note: cisco.sdwan 0.3.5 contains no modules, only playbooks built on cisco.catalystwan and the roles in cisco.sdwan_deployment.

Credential-safe by design: This page is a static catalogue and never contacts a controller. Connection options use the placeholders {{ manager_url }} {{ manager_username }} {{ manager_password }} {{ manager_port }} from inventory.yml, and every password, key, token or community value in a model is a {{ vault_… }} placeholder. Every module that can change state is tagged never in its playbook, so site.yml runs only read-only modules unless you ask for a tag.

Files, models and samples

All 26 items are published as real files, plus combined files and a single sample data model.

  • site.yml: combined playbook that imports every playbook in build order (state-changing plays are tagged never)
  • sample/sdwan-model.yml: combined sample data model
  • inventory.yml and ansible.cfg: placeholders only
  • playbooks/filter_plugins/cat_model.py: null-stripping filter used by every playbook
  • models/<module>.yml: one model per item, each opening with a references block
  • playbooks/<NNNN>_<module>.yml: one numbered sample playbook per item

Syntax-check locally with the collection installed:

ansible-galaxy collection install cisco.catalystwan:0.3.2
ansible-playbook --syntax-check -i inventory.yml site.yml
# Read-only run (info modules only; every state-changing play is tagged never):
ansible-playbook -i inventory.yml site.yml

Collection: cisco.catalystwan 0.3.2 (26 modules in plugins/modules/), the latest on Ansible Galaxy on 26 Nov 2026, installed and read with ansible-doc --json. Two modules (cluster_management, feature_profile_builder) ship a DOCUMENTATION block that does not parse, so they are listed without options. cisco.sdwan 0.3.5 is the companion collection: it has no modules of its own, only playbooks that drive cisco.catalystwan and the cisco.sdwan_deployment roles (Galaxy, GitHub), so it adds no items here.

Folder links end with /. Credentials are placeholders only ({{ manager_url }} {{ manager_username }} {{ manager_password }} {{ manager_port }}). Addresses are documentation ranges only (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24); other example addresses copied from upstream docs were moved into those ranges. No live device or controller was contacted; device output is not collected.
