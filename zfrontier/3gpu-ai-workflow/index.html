🧮 3-GPU AI Workflow

A local Windows 11 PC with three GPUs, three models and LangGraph as a CPU orchestrator, used to build and verify a Python trading backtest. The diagram below is an accessible HTML/SVG redraw of the design (the original PNG is not published). Facts were checked against official sources on 13 Nov 2026 (Melbourne time).

Host: Windows 11 · MSI MAG X870E Tomahawk WIFI · AMD Ryzen 9 7950X · 192 GB RAM (as drawn). Scroll the diagram sideways on a phone.

LangGraph on the CPU sends the same task to three local API servers. The RTX 5090 is the lead developer running Qwen3.8-Flash-Next. The Radeon PRO W6800 is the reviewer running Qwen3-Coder-30B-A3B Instruct at Q4_K_M. The RTX 5060 Ti is the repository assistant running Qwen3-8B at Q6_K. LangGraph collects the results, CPU tools run pytest, lint and backtest fixtures, and acceptance checks either loop back to the 5090 for repairs or pass to the 5090 for final integration. The 5090 may offload weights to system RAM; the two helper models and their KV caches stay in VRAM. GPU memory is not pooled.

The three roles

Lead developer

RTX 5090 32 GB · PCI_E1 · PCIe 5.0 x16

Qwen3.8-Flash-Next, NVFP4, Strata / CUDA. Plans architecture, implements signal and execution logic, repairs findings and does final integration.

Second coder / reviewer

Radeon PRO W6800 32 GB · PCI_E3 · PCIe 4.0 x4

Qwen3-Coder-30B-A3B Instruct, Q4_K_M, llama.cpp / Vulkan. Implements an isolated module, reviews timing and look-ahead bias, and returns tests and counterexamples.

Repository assistant

RTX 5060 Ti 16 GB · PCI_E2 · PCIe 3.0 x1

Qwen3-8B, Q6_K, llama.cpp / CUDA. Locates callers, prepares fixtures and simple tests, and classifies failures with file references.

Short verdict

Fail The lead model does not fit in the 5090's 32 GB if the weights stay on the GPU. Qwen3.8-Flash-Next is officially a 125-billion-parameter MoE with 6 billion activated, plus 51 billion n-gram embeddings and a 4 billion MTP module [1]. An all-NVFP4 estimate of the main 125B weights alone is 70.31 GB (125B × 4.5 bits ÷ 8) [2]. NVIDIA's own local checkpoint is about 96 GiB on disk and was validated on an RTX PRO 6000 Blackwell or a DGX Spark, not on a 32 GB GeForce [3].

Warn The design can only work the way it is drawn if most of that model is offloaded to the 192 GB of system RAM, which is the stated memory policy. A third-party engine called Strata targets this model on consumer hardware [4]. It is not on Qwen's recommended runtime list (SGLang, vLLM, TokenSpeed, KTransformers) or on NVIDIA's validated hardware list for the official NVFP4 checkpoints [1] [5] [3].

Pass The two helper cards can hold their models in VRAM at a moderate context: the official Qwen3-8B Q6_K GGUF is 6.726 GB, and a Q4_K lower bound for the 30.5B coder model is 17.16 GB [6] [7] [8]. Warn Full native context on the coder card (262,144 tokens, KV staying in VRAM) does not fit. The MSI slot layout matches the diagram [9]. Warn Combined board power of the three GPUs is 1,005 W, plus a 170 W CPU, which is already above NVIDIA's 1,000 W recommendation for the 5090 alone [10] [11] [12] [13].
