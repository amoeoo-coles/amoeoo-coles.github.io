Verdict: what it can and cannot run

Best role: orchestrator and verification node, not a three-GPU host. A 24-core 285HX, up to 256 GB of RAM, 10 GbE plus (on 285HX) dual 25 GbE, and a 350 W internal PSU make it a strong machine to run LangGraph, pytest, lint, type checks and backtest fixtures, while the X870E PC keeps the three model servers [1].

Fail It cannot host the RTX 5090. That card is 575 W TGP and NVIDIA asks for a 1,000 W system PSU [3]; the Ultra's built-in PSU is 350 W [1].

Fail It cannot reasonably host the Radeon PRO W6800 either. That card is 250 W TBP, full height, 10.5 inches and dual slot [4]. Officially the Ultra accepts a dual-slot desktop GPU, but 250 W plus a reduced 90–110 W CPU budget is already 340–360 W before the board, RAM, NICs and drives, against a 350 W PSU [1] [4].

Warn A single modest dual-slot GPU in the PCIe 5.0 x16 slot is possible on paper (the CPU TDP then drops to 90 W / 110 W on 285HX) [1]. The official 5060 Ti is 180 W TGP [5]; 180 W + 90–110 W leaves about 60–80 W for the rest of a 350 W box, which is tight and not a combination Minisforum has published. I did not find an official list that names a 5060 Ti (or a 5060 Ti low-profile card) as supported.

Not verified An external GPU over USB4 V2 (80 Gbps) is suggested only in general terms — the store page says USB4 v2 is for "external storage, displays, and acceleration modules" [1]. There is no official eGPU compatibility list and no official OCuLink path. Treat eGPU as unproven on this chassis until Minisforum publishes one.

Phased future plan

Dated as of 13 Nov 2026 (Melbourne time). Later phases are options, not commitments. Each phase should be estimated again before it is built.

Phase 0 — today, on the X870E PC

Keep all three model servers on the current Windows 11 PC. Run LangGraph and the CPU verification tools on the 7950X. Work through the bring-up checklist. Do not move a 5090 or a W6800 into the Ultra. Confirm the PSU, cooling and the 192 GB memory configuration against the warnings on the design-check page.

Phase 1 — add the MS-02 Ultra as the orchestrator

Stand up an MS-02 Ultra (285HX if you want 25 GbE and ECC) with enough RAM for LangGraph state, checkpoints and test fixtures. Connect it to the X870E PC over 10 GbE, or 25 GbE if both ends can take it. Move LangGraph, pytest, lint, type checks and backtest fixtures onto the Ultra. The three model APIs stay on the X870E PC and are reached over the LAN. This is the step that official specs clearly support.

Phase 2 — optional small GPU in the Ultra

Only if Phase 1 is stable and a published, power-appropriate dual-slot card is chosen against the 350 W PSU and the reduced 90 W / 110 W CPU budget. A possible use is a small local model (for example a repository assistant) so that the 5060 Ti path is no longer required on the X870E box. This phase is not verified: Minisforum has not published a supported-card list or a wattage cap for that slot [1].

Phase 3 — only if an official eGPU path appears

Revisit USB4 V2 (80 Gbps) "acceleration modules" if Minisforum or a dock vendor publishes an official eGPU compatibility statement for the MS-02 Ultra. There is no official OCuLink port to plan around [1] [2]. Until that documentation exists, do not treat an eGPU as part of the design.
