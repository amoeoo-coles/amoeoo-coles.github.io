🗄️ Chassis

2 UCSX-9508 chassis (pod1-1 and pod2-1) with 9108-100G fabric modules, both healthy. Organization SNG-AI1. In Intersight: Operate > Chassis · Operate > Chassis (fewer columns).

Findings

  • Data check pod2 blades are missing from the servers export

    Chassis sng-ai1-pod2-1 is Healthy with chassis profile SNG-AI1-FI2-Chassis1, target sng-ai1-pod2 is Connected, and server profiles point at sng-ai1-pod2-1-1, sng-ai1-pod2-1-3, but the servers export lists only the 5 pod1 blades. The export was probably filtered. Export Operate > Servers again with no filter to see pod2.

    Report pages: Servers · Chassis · Server Profiles
  • Info Short chassis export is a subset of the full one; duplicate uploads removed

    The short chassis export has 1 row (sng-ai1-pod1-1) and matches the full export (2 rows), so both are on the Chassis page. 31 CSV files were uploaded; 14 are exact duplicates (same content after removing the byte-order mark), leaving 17 unique datasets. See the dataset inventory on the Reports hub.

    Report pages: Chassis
  • Good FI firmware is consistent

    All 4 FIs run bundle 4.3(5.250011) with NX-OS 9.3(5)I43(5d). The server and chassis exports have no firmware column, so blade and IFM firmware cannot be checked from these files. The software repository holds only SCU images, no UCS firmware bundles.

    Report pages: Fabric Interconnects · Servers · Chassis · Software Repository
  • Good Support contract Active on all 6 FIs and chassis

    All use one contract number (****0144, masked). Location fields are empty in both exports.
