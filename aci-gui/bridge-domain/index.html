What is a Bridge Domain?

From the Cisco Live lab: a Bridge Domain (BD) is a Layer 2 representation inside the ACI fabric. The BD is where you define the anycast gateway/subnet that provides the default gateway for hosts attached to the fabric.

A subnet under the BD can have these scope options (lab wording, with the GUI labels used in the wizard):

  • Public (GUI: Advertised Externally) — ACI advertises this subnet outside the fabric. You do not have to build a route-map yourself.
  • Private (GUI: Private to VRF) — the subnet stays within the tenant. This is the default when neither scope box is checked.
  • Shared (GUI: Shared between VRFs) — the subnet can be shared with another VRF in the same tenant. The lab notes that if you enable this, you should use different subnets.

This page creates the two BDs from lab LTRDCN-2143, Create Bridge Domains. Names, VRF, gateway addresses, the Advertised Externally / Private to VRF choice, and the aci_p01_L3out association come from that lab step. Wizard details that the lab text does not list — Type regular, Forwarding Optimize, Unicast Routing, ARP Flooding, MAC address 00:22:BD:F8:19:FF, ND RA Prefix, IP Data-plane Learning, and the Advanced/Troubleshooting defaults — come from Aung's APIC screenshots of the same wizard. Values that were not shown are left unset and called out as such. The form replicas below are static; the controls are not functional.

NaC YAML for this exact example

Keys checked against the local Cisco NaC module (terraform-aci-bridge-domain): name, vrf, advertise_host_routes, unicast_routing, arp_flooding, mac, ep_move_detection, multicast_arp_drop, l3outs, and on each subnet ip, public, shared, virtual, primary_ip, nd_ra_prefix, no_default_gateway, igmp_querier, ip_dataplane_learning. The module has no separate private key: a subnet with public: false and shared: false is Private to VRF. Type regular and Forwarding Optimize are not written as NaC keys here, because their mapping was not given in the lab or the screenshots.

YAML
apic:
  tenants:
    - name: aci_p01_tenant
      bridge_domains:
        - name: aci_p01_bd_web
          vrf: aci_p01_vrf
          advertise_host_routes: false
          unicast_routing: true          # Unicast Routing: Enabled
          arp_flooding: true             # ARP Flooding: Enabled
          mac: "00:22:BD:F8:19:FF"       # Config BD MAC Address ticked
          ep_move_detection: false       # GARP based detection unchecked
          multicast_arp_drop: true       # Drop ARP with Multicast SMAC (Advanced)
          subnets:
            - ip: 10.0.144.1/29
              public: true               # Scope: Advertised Externally
              shared: false              # Scope: Shared between VRFs unchecked
              virtual: false
              primary_ip: false
              nd_ra_prefix: true         # Subnet Control: ND RA Prefix
              no_default_gateway: false
              igmp_querier: false
              ip_dataplane_learning: true
          l3outs:
            - aci_p01_L3out
        - name: aci_p01_bd_app
          vrf: aci_p01_vrf
          advertise_host_routes: false
          unicast_routing: true
          arp_flooding: true
          mac: "00:22:BD:F8:19:FF"
          ep_move_detection: false
          multicast_arp_drop: true
          subnets:
            - ip: 172.16.1.1/24
              public: false              # both scope boxes unchecked = Private to VRF
              shared: false
              virtual: false
              primary_ip: false
              nd_ra_prefix: true
              no_default_gateway: false
              igmp_querier: false
              ip_dataplane_learning: true
          # Associated L3 Outs was left empty
