What is an Application Profile?

Endpoints such as laptops, printers, and servers each do a specific job, and administrators need a way to classify those devices and control what they can talk to. In ACI, endpoints that share the same policy are grouped into EPGs (endpoint groups). That is like grouping devices in an access list: you define the policy on the EPG, and every device in the group inherits it. For example, if web servers should allow only ports 80 and 443 inbound, you place those servers in an EPG with that policy.

The Application Profile is the collection of policy definitions for how EPGs talk to each other — contracts, filters, and service graphs. You might have a WEB EPG that accepts 80/443 from external users and talks to a DB EPG on port 3306. Those relationships can be built by a network administrator or even by the application itself.

ACI is a whitelist model: EPGs cannot talk to each other unless a contract allows it. That is the opposite of a traditional network, where anything in the same VRF can communicate until something is added to block it. A contract can be as simple as permitting a port, or as complex as a service graph with policy-based redirects.

This section creates the Management Application Profile used in the lab to attach VMs so they can obtain DHCP addresses. In some deployments the same profile also carries SSH, virus updates, and similar management traffic. It builds on Mgmt Bridge Domain and DHCP Relay.

Context for this topic comes from the public Cisco Live ACI lab guide page Create MGMT Application Profiles (LTRDCN-2143, pod1). NaC YAML

apic:
  tenants:
    - name: aci_p01_tenant
      application_profiles:
        - name: aci_p01_ap_mgmt
          endpoint_groups:
            - name: aci_p01_epg_mgmt
              bridge_domain: aci_p01_bd_mgmt
              # Domain in the GUI is aci_p01_dc3_vds (VMware VMM)
              domains:
                - aci_p01_dc3_vds
              contracts:
                providers:
                  - name: mgmt-ltraci-2143
                    # Provided Contract column shows common/mgmt-ltraci-2143
                # Consumed Contract was blank
