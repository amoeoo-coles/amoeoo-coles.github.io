Finish the VMM integration on the vSphere side: add host pod01-compute1 to DVS aci_p01_dc3_vds and assign vmnic2/vmnic3 to the two links of enhanced LAG lag1. This is a vSphere Client wizard, not an APIC form.

vSpherevmmDomP

This page follows the Create Subnet layout: each of Aung's ten screenshots sits beside an HTML replica of the same vSphere window or wizard page. Values are taken from those screenshots and from the public Cisco Live lab page linked below. There is no password on this page.

This is a vSphere Client wizard, not an APIC dialog. The distributed switch aci_p01_dc3_vds and the enhanced LAG lag1 (two links, lag1-0 and lag1-1) come from the Create VMM Domain page. A public walk-through of the same lab step is https://aci-lab.ciscolive.com/lab/pod1/acivmm/add-hosts-dvs (Cisco Live LTRDCN-2143, pod 1).

Step 1 — Open the inventory, then Networking

In the vSphere Client, the inventory tree under vCenter6.ecatsrtpdmz.cisco.com > Cisco Live > dc_pod01 > pod01_cluster shows host pod01-compute1, pod01_resource_pool, and VMs POD01-APP-SRV, POD01-DB-SRV, POD01-WEB-SRV-01 and POD01-WEB-SRV-02. Click the Networking tab (the globe icon). The right pane in this screenshot reads: You have no privileges to view this object or it does not exist.

Step 6 — Manage physical adapters: assign vmnic2 to lag1-0

On 3 Manage physical adapters, Adapters on all hosts is selected. vmnic0 is In use by switch 1 host / 1 Switch, Assign uplink None. vmnic1 through vmnic5 show 1 host / 0 switches and None. Open the Assign uplink list on vmnic2. The list is None, uplink1–uplink8, lag1, lag1-0, lag1-1 and (Auto-assign). Choose lag1-0. These lag members are the two links of enhanced LAG lag1 from the VMM Domain page.
