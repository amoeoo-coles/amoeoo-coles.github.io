Management EPGs in the mgmt tenant are what static node management addresses bind to — default for out-of-band, a named in-band EPG such as InBand-Mgmt for in-band.

In-Band ▾

In-band creates mgmtInB at uni/tn-mgmt/mgmtp-default/inb-{name}. Out-of-band uses mgmtOoB (the fabric already has oob-default).

NaC YAML

YAML
apic:
  tenants:
    - name: mgmt
      inb_endpoint_groups:
        - name: InBand-Mgmt
          # typically references the in-band BD / VRF and a VLAN encap
      oob_endpoint_groups:
        - name: default
