YAML Model

Network-as-Code (nac-aci data model) YAML generated from the ACI tenants in NetBox, the source of truth, using the same schema as the aci-nac pipeline (apic: tenants: → VRFs, bridge domains with subnets, application profiles → EPGs). Built-in tenants common/infra/mgmt are left out because NetBox holds no user objects in them. Each tenant also has a section-anchored view (for example /netbox-yaml-model/cursor-tenant5/#bd-cursor5_app_bd) that the tenant diagrams link to. See NetBox ACI Tenants for the tree view and AOAPIC status, and Tenant Diagrams for the clickable 📄 icons.
