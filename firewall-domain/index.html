Update · 11 Nov 2026 (AEDT) — Cisco FMM demo migration review

Project 1 (Palo Alto vsys3 → FTD ftdv1) completed: 2658 objects (12 interfaces, 1243 network, 253 port, 1027 URL, 80 access rules, 43 apps). Open: URL count 927 vs 1027 in the UI; unmapped apps Netflow, ms-kms, smtps; site-to-site VPN and Security Intelligence not migrated; AD/LDAP realm flagged; confirm PAN→FTD interface auto-map against cabling; demo FMC cert bypass; rotate FMC admin credential after screenshot exposure. Project 2 (ASA 8.4+ → FTD) in progress: no FTD selected yet; inside/outside zones mapped; RA VPN pool and IKEv2 endpoints pending validation; RA certificate still needed on trustpoint.

Firewall Domain

Firewall Domain

A documentation group for firewall migration tools and a structured Cisco ASA build. It covers Cisco’s Secure Firewall Migration Tool, Palo Alto Expedition and the official Panorama import workflow, short notes on FortiConverter and Check Point migrate_server, and an example ASA active/standby build. Every fact below is cited. Example addresses use documentation ranges and every secret is written as <REPLACE>.

Aung’s names “Cisco firewall Migration Manager” and “PaloAlto Panorama Migration Manager” are mapped here to the official products those phrases usually mean: Cisco’s Secure Firewall Migration Tool (desktop or hosted on Security Cloud Control) and, on the Palo Alto side, Expedition plus the built-in Import device configuration to Panorama workflow. There is no separate Cisco product currently documented as “Firewall Migration Manager”, and Expedition is the name Palo Alto used for its migration tool.
