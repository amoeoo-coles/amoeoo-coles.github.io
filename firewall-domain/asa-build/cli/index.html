Example CLI configuration

Primary-unit example for the build described on the sibling pages. Copy or download it, replace every <REPLACE>, and change interface IDs to match your hardware. Source: Cisco ASA 9.20 General Operations CLI: Failover for High Availability Source: Cisco ASA 9.20 General Operations CLI: Routed and Transparent Mode Interfaces Source: Cisco ASA 9.20 General Operations CLI: Management Access Source: Cisco ASA 9.20 General Operations CLI: Static and Default Routes Source: Cisco ASA 9.20 General Operations CLI: Licenses: Smart Software Licensing

Example values. RFC 5737 addresses only. The Smart Licensing block is the ASA Virtual procedure; omit it on hardware that registers another way. hostname, domain-name and enable password come from the Basic Settings chapter of the same book.

Primary unit

Download .cfg
CFG
! Example Cisco ASA active/standby pair. Documentation addresses only.
! Commands below are taken from the ASA 9.20 General Operations CLI guide
! chapters cited on /firewall-domain/asa-build/cli/.
! Replace every <REPLACE> value before use. Never paste a real password here.
!
! Interface IDs follow the 9.20 failover chapter examples (GigabitEthernet0/x).
! Newer Firepower and Secure Firewall platforms use Ethernet1/x or similar;
! match the hardware installation guide for your model.
!
! Hostname, domain-name and enable password are Basic Settings commands
! listed in the same book. They are included here so the example is bootable.

hostname ASA-PRIMARY
domain-name example.test
enable password <REPLACE>
username admin password <REPLACE> privilege 15

! ASAv Smart Licensing only (skip on hardware that uses a different procedure).
! Throughput levels published for ASAv: 100M, 1G, 2G, 10G, 20G.
license smart
 feature tier standard
 throughput level 1G
license smart register idtoken <REPLACE>

interface GigabitEthernet0/0
 nameif outside
 security-level 0
 ip address 203.0.113.1 255.255.255.0 standby 203.0.113.2
 no shutdown

interface GigabitEthernet0/1
 nameif inside
 security-level 100
 ip address 192.0.2.1 255.255.255.0 standby 192.0.2.2
 no shutdown

! Failover and state links: do not configure nameif on these interfaces.
interface GigabitEthernet0/3
 description LAN failover link
 no shutdown

interface GigabitEthernet0/4
 description Stateful failover link
 no shutdown

failover lan unit primary
failover lan interface folink GigabitEthernet0/3
failover interface ip folink 198.51.100.0 255.255.255.254 standby 198.51.100.1
failover link statelink GigabitEthernet0/4
failover interface ip statelink 198.51.100.2 255.255.255.254 standby 198.51.100.3
failover ipsec pre-shared-key <REPLACE>
failover

route outside 0.0.0.0 0.0.0.0 203.0.113.254 1

aaa authentication ssh console LOCAL
aaa authentication http console LOCAL
aaa authentication enable console LOCAL
crypto key generate rsa modulus 2048
ssh 192.0.2.0 255.255.255.0 inside
http server enable
http 192.0.2.0 255.255.255.0 inside

object network OBJ_INSIDE
 subnet 192.0.2.0 255.255.255.0
nat (inside,outside) source dynamic OBJ_INSIDE interface

access-list OUTSIDE_IN extended permit icmp any any echo-reply
access-group OUTSIDE_IN in interface outside

write memory

Secondary unit (failover link only)

After the primary has failover enabled, configure the secondary with the same failover-link commands. Secondary is the default unit role.Source: Cisco ASA 9.20 General Operations CLI: Failover for High Availability

CLI
failover lan interface folink GigabitEthernet0/3
failover interface ip folink 198.51.100.0 255.255.255.254 standby 198.51.100.1
interface GigabitEthernet0/3
 no shutdown
failover link statelink GigabitEthernet0/4
failover interface ip statelink 198.51.100.2 255.255.255.254 standby 198.51.100.3
interface GigabitEthernet0/4
 no shutdown
failover ipsec pre-shared-key <REPLACE>
failover
write memory
