Create Mgmt Bridge Domain

A separate management BD gives workloads a path to shared services such as PXE, SSH and DNS. This is the lab's first use of a shared L3Out: the BD is placed in the existing k8s_vrf and associated with the shared L3Out named k8s, with the subnet advertised externally. That shared VRF and L3Out already exist in the lab fabric; they are not created in this step.

Aligned with the public Cisco Live ACI lab guide (lab code LTRDCN-2143, pod1). Lab usernames and passwords from the guide's credentials dropdown are not republished here. No APIC writes are performed from these pages.

View the original step: Create Mgmt Bridge Domain on the Cisco Live ACI lab guide (LTRDCN-2143, pod1). Summaries here are in our own words; the official wording stays on Cisco's page.

NaC YAML

Illustrative Cisco NaC using the pod1 names from the lab guide. This is documentation only; do not push it to a fabric from this page.

YAML
apic:
  tenants:
    - name: aci_p01_tenant
      bridge_domains:
        - name: aci_p01_bd_mgmt
          vrf: k8s_vrf
          unicast_routing: true
          subnets:
            - ip: 10.0.145.1/29
              public: true
              private: false
          l3outs: [k8s]
