NB Tenant Diagrams

Diagrams of NetBox-driven ACI tenants only — the tenants the NetBox ACI plugin holds as the source of truth, other than the built-in common, infra and mgmt tenants. Each tenant has its own containment diagram below (Tenant → VRF → bridge domain and subnets → EPG). Open a tenant page for the tree view, object table and YAML links. The 📄 icon on a box opens that object’s section in the YAML model. Colours show whether an object is in both NetBox and AOAPIC, in NetBox only, or on AOAPIC only.
