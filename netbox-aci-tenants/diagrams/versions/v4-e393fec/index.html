NB Tenant Diagrams

Diagrams of NetBox-driven ACI tenants only — the tenants the NetBox ACI plugin holds as the source of truth, other than the built-in common, infra and mgmt tenants. Each card opens a page with the tenant’s diagram (containment view first, then the tree view: Tenant → VRF → bridge domain and subnets → EPG, with contract arrows and L3Outs when they exist) and an object table. The 📄 icon on a box opens that object’s section in the YAML model. Colours show whether an object is in both NetBox and AOAPIC, in NetBox only, or on AOAPIC only.
