🧠 MindMap

A map of the Universal Provisioning Infrastructure as Code demo. The centre is the demo itself; each coloured branch is a menu group or a flow area, and the outer nodes are the pages. Click a branch to zoom in and see only that branch. Click a page name (a node with no further branches) to open it. Menu groups come from the live site menu so this map stays in sync.

Tip: drag to pan, scroll or pinch to zoom, use Back or Esc to zoom out, and press / to search. The coloured chips under the map jump to that branch; click the active chip or Home to return to the overview. The ↗ on a branch opens that page without zooming in. The light/dark toggle in the top-right inverts the page; the map stays readable in both themes.
