A map of the Universal Provisioning Infrastructure as Code demo. The centre is the demo itself; each coloured branch is a menu group or a flow area, and the outer nodes are the pages. Click a node to open that page. Use the coloured − / + on a branch to collapse or expand its pages. Menu groups come from the live site menu so this map stays in sync.
